# 1d100 自動ダイスローラー (Google Apps Script)

10秒ごとに自動で1d100のダイスを振り、クリティカル（1〜5）とファンブル（95〜100）を自動カウントするGoogle Apps Script（GAS）ウェブアプリケーションです。

## セットアップ手順

1. [Google Apps Script](https://script.google.com/) で新規プロジェクトを作成します。
2. `Code.js` の内容を `コード.gs` に貼り付けます。
3. 新しいHTMLファイル `Index.html` を作成し、`Index.html` の内容を貼り付けます。
4. 画面右上の「デプロイ」 > 「新しいデプロイ」 を選択します。
5. 種類を「ウェブアプリ」に設定し、アクセス権限を指定してデプロイします。
